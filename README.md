Official PyTorch implementation for **MAMamba‑DFI** (Mask‑Aware Mamba with Dual‑Stream Interaction and Dynamic Frequency Enhancement for Image Inpainting).

This work introduces:

1. **MDI (Mamba‑based Dual‑stream Interaction)** module: global mask‑aware Mamba stream + local multi‑scale convolution stream with bidirectional cross‑gating and GUSS scanning strategy.
2. **MAD (Mask‑Guided Attention Downsampling)**: suppress hole‑noise leakage and mitigate feature misalignment during down‑sampling.
3. **DHFL (Dynamic High‑Pass Frequency‑domain Loss)**: architecture‑loss synergy together with FDEFN module for high‑frequency texture and edge enhancement.

Extensive experiments on Places2, Paris Street View, CelebA‑HQ, Dunhuang Grottoes demonstrate superior quantitative metrics (PSNR / SSIM / MAE / LPIPS / FID) and visual restoration quality compared with state‑of‑the‑art inpainting methods.

## 📊 Dataset Preparation

We use four datasets in the paper:

1. **Places2** (natural scene)
2. **Paris Street View** (building street)
3. **CelebA‑HQ** (high‑resolution face)
4. **Dunhuang Grottoes** (mural heritage restoration)

### Step1: Prepare image and mask folders

- Images: RGB images, resized to `256 × 256`.
- Masks: binary mask image, `255` for missing hole region, `0` for valid known region.

### Step2: Generate flist file

```
# generate image flist
python src/flist.py --path ./dataset/places2/train/img --output ./dataset/places2_train_img.flist
python src/flist.py --path ./dataset/places2/test/img --output ./dataset/places2_test_img.flist

# generate mask flist
python src/flist.py --path ./dataset/masks/train --output ./dataset/mask_train.flist
python src/flist.py --path ./dataset/masks/test --output ./dataset/mask_test.flist
```

> 
> The `MASK` parameter in config.yml controls mask mode:
> 
> 
> - `MASK=3`: read external mask files from mask flist (used for fixed‑ratio test set in paper).
> - `MASK=1`: random block mask generated on‑the‑fly for training.

### Dataset configuration mapping in `config.yml`

```
TRAIN_INPAINT_IMAGE_FLIST: "./dataset/places2_train_img.flist"
TEST_INPAINT_IMAGE_FLIST: "./dataset/places2_test_img.flist"
TRAIN_MASK_FLIST: "./dataset/mask_train.flist"
TEST_MASK_FLIST: "./dataset/mask_test.flist"
```

## 🚀 Training

```
# training, point to your checkpoint directory containing config.yml
python train.py --path ./checkpoints/exp_places2
```

Or use main.py directly:

```
python main.py --path ./checkpoints/exp_places2
```

Training workflow:

1. Load dataset from `.flist` files.
2. InpaintingModel (`src/models.py`) run `process()` for forward pass, compute total loss combining L1 / perceptual / style / adversarial / DHFL.
3. `backward()` update discriminator and generator, gradient clipping max_norm=1.0.
4. Save weights:
   - latest weight: `InpaintingModel_gen.pth`, `InpaintingModel_dis.pth`
   - history checkpoint every xxxx iterations: `InpaintingModel_gen_xxxx.pth`
5. Log training loss, psnr, mae to log file and wandb. Intermediate visual samples saved under `checkpoints/exp_places2/results/inpaint/`.

> 
> Weights will be loaded automatically if checkpoint files exist (resume training supported).

## 🔍 Testing / Inference

```
python test.py --path ./checkpoints/exp_places2
```

Test mode will:

1. Read test image and mask flist from config.
2. Run model evaluation (`model.eval()`, `torch.no_grad()`).
3. Output three kinds of images: masked input, raw network output, merged result(original known region + inpainted hole).
4. Automatically compute **PSNR, SSIM, L1, LPIPS** for every test sample and print mean metrics on terminal.

Output directory:

```
checkpoints/exp_places2/results/inpaint/
├── masked4060/      # masked input image
├── result4060/       # final merged inpainting result
└── joint4060/       # concatenated comparison image(gt | masked | raw output | merged)
```

> 
> For single image inference (not included in current code): you can write simple wrapper feeding single image‑mask tensor pair to `inpaint_model(images, masks, mask_half, mask_quarter, mask_tiny)`. Remember to generate multi‑scale downsampled masks same as `models.py forward()`.

## ✅ Reproduce Paper Tables & Figures

### Tables

1. **Table2 (d_state ablation)**: modify `vmamba.py EfficientSS2D d_state` argument (16 / 32 /64), retrain on Places2 fixed test set.
2. **Table3 (MDI block number ablation)**: modify `networks.py MAMamba‑DFI num_blocks=[...]`, retrain on Places2.
3. **Table4‑7 (main comparison across four datasets)**: use corresponding dataset flist, run test script, group metrics by mask ratio bins.
4. **Table8 (LPIPS & FID)**: LPIPS is printed by test code; compute FID by third‑party FID tool using test result folder and gt folder under mask interval (0.3,0.4].
5. **Table9 (additional mamba‑based baseline comparison)**: For DESSM run official released code under identical training/test protocol; for HSCM / InpaintingMamba / DABMambaII report original paper numbers as described in our manuscript.
6. **Table10‑11 (ablation on Dunhuang)**: turn on/off modules in code:
   - w/ ConvDown: replace `MaskAwareSDPDownsample` with ordinary `nn.Conv2d(stride=2)`
   - w/o DHFL: set `FFL_LOSS_WEIGHT:0.0` in config.yml
   - w/o Local / w/o Global: comment corresponding branch inside `DualStreamBlock`
   - w/o FDEFN: comment `edffn` forward call
   - w/o GUSS: disable flip/transpose transformation in `MaskAwareSSM`
   - w/ Add: replace `BiInteractionUnit cross‑gating` with simple element‑wise addition
   - w/o Mask: remove mask fill `-1e9` in attention of `MaskAwareSDPDownsample`
   - w/o HPF: set `use_hpf=False` when initialize `FocalFrequencyLoss`

### Figures

1. **Qualitative comparison**: collect test joint images from `joint4060` folder, crop and arrange sub‑plots as in manuscript.
2. **Architecture diagram**: these are vector schematic diagrams drawn manually in paper, not generated from code.
3. **Curve plots**: take test grouped metrics data (Table4‑7 numbers), draw line chart with matplotlib.
4. **Ablation visual comparison**: collect test outputs from each ablation variant checkpoint.
